# ADR-0005: Apache-2.0 as project license

**Status:** Accepted (2026-09-24). Replaces the initial MIT license.

Apache-2.0 is permissive like MIT and adds an explicit patent grant, which suits
a platform with a third-party extension ecosystem. A `NOTICE` file carries the
copyright; third-party notices are in `THIRD-PARTY-NOTICES.md`.
